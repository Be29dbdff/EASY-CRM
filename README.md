# EASY-CRM

Prototype de CRM pour cabinet d'assurance. Ce dépôt contient un backend Node.js minimal illustrant la gestion des clients et l'authentification JWT.

## Lancer le backend

```
cd backend && npm install && npm start
```

## Fonctionnalités principales prévues
- Tableau de bord avec indicateurs (contrats actifs, relances, nouveaux devis, sinistres en cours)
- Fiche client (données personnelles, contrats, historique des devis et sinistres)
- Gestion des contrats avec filtres et édition
- Module de devis dynamique
- Tâches / Agenda pour les relances
- Interface administrateur (utilisateurs, rôles, droits)

Ce dépôt est un point de départ : seules quelques routes d'API sont disponibles pour l'instant.
