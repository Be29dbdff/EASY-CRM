# Dossier des livrables Easy Insure

Ce dossier regroupe tous les éléments remis :

- **Site web** : `site/index.html` et le dossier `site/assets/` pour les ressources graphiques.
- **Documentation** : `docs/cahier_des_charges.md` décrivant le projet, l’architecture et la direction artistique.

## Comment utiliser

1. Ouvrez `site/index.html` pour visualiser la page d’accueil du comparateur Easy Insure.
2. Consultez `docs/cahier_des_charges.md` pour les détails fonctionnels, UX/UI et le planning projet.
3. Les assets peuvent être adaptés dans `site/assets/` si vous souhaitez personnaliser le branding.

Bon projet !
